About CineLog

A student project made with HTML, CSS and JavaScript.

What can you do here?

  1. Login as a User or as an Admin.
  2. Search and filter 100+ movies.
  3. Save movies in your Watchlist.
  4. Rate movies and write reviews in your Diary.
  5. Admin can add or delete movies and manage users.

Technologies used

  • HTML5 - structure of the pages
  • CSS3 - colours, layout and animations
  • JavaScript - all the interactive features
  • Local Storage - saves data in the browser
